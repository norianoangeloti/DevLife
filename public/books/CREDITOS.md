# Acervo em português

## Desenvolvimento para Web — volumes HTML e CSS

Joaquim Celestino Júnior e Robério Gomes Patricio. UECE/UAB, 2ª edição, 2015.
Fonte oficial: https://educapes.capes.gov.br/handle/capes/432205
PDF original: https://educapes.capes.gov.br/bitstream/capes/432205/2/Livro_Desenvolvimento%20para%20Web.pdf

html.pdf e css.pdf são cópias integrais, inalteradas. O leitor apresenta as seis páginas iniciais de créditos e o capítulo correspondente: HTML, páginas físicas 18–37; CSS, 38–52. Os volumes têm 26 e 21 páginas de leitura. Os exemplos são introdutórios e históricos; algumas práticas HTML da edição foram substituídas por CSS.

O registro oficial eduCAPES disponibiliza o material sob Creative Commons Atribuição–NãoComercial–CompartilhaIgual 3.0 Brasil: https://creativecommons.org/licenses/by-nc-sa/3.0/br/. O aviso editorial original de 2015 permanece no PDF com todos os créditos.
